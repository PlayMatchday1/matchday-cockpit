Mockup data note. NEMP is entirely real, taken from the live card: 54 ran matches over Jul 6 – Aug 2, $15,409 gross, $4,158 field cost, $11,251 net, split $10,835 paid (DPP) + $4,574 allocated member. Every per-match figure here is that data divided by 54. Every other field row is blank on purpose — the screenshot only exposed NEMP, and inventing plausible rows for a profitability ranking is exactly the wrong thing to fake. Promo is shown as its own revenue line but has no value, because paid revenue was not split by spot type in the source; the live build separates DPP / membership / promo. The 1 and 2 week windows re-render the same figures for the same reason.
